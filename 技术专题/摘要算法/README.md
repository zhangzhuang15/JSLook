## Description
在一些场景下，我们需要判断某些事情是否发生过，某些数据是否获取过。直观的思路就是存储数据，
然后经过查找，判断数据是否存在。但是，受限于数据的体量，这种方法的效率不稳定。数据量小的
时候，效率高；数据量大的时候，效率低。

对于这样的问题，有没有什么方法去标记数据的唯一性呢？

这就是摘要算法的作用了。摘要算法也叫哈希算法。它可以将不固定长度的数据，处理为固定长度的
值，用这个值叫做摘要值，或者哈希值，表示原始数据，如果有另外的一个数据拥有相同的哈希值，表示
两个数据相等。

利用摘要算法，可以做很多事情。比如：
- 实现 hashMap
- 实现 cache
- 判断 原始数据有没有被修改
- 数字签名 

## 常见的摘要算法
### MD5 
MD5是一种常见的消息摘要算法，用于对任意长度的消息进行哈希运算，生成唯一的**128位**（16字节）的值。其可以将数据快速、安全地压缩为一个不可逆的指纹字符串，常用于数字签名、密码存储和防篡改等领域。MD5算法具有高效快速、安全性高等优点。
### SHA-1
SHA-1是一种基于Merkle–Damgård结构的哈希算法，是SHA算法族中的一个成员。SHA-1以512位的消息分块为基础，产生一个**160位**的消息摘要。与MD5相比，SHA-1更为安全可靠，具有更高的安全性和抗碰撞性，因此逐渐取代了MD5成为最常用的哈希算法之一。
### SHA-256
SHA-256是SHA-2算法族中的一种，其是一种可靠的哈希算法，采用512位的分块方式来处理消息，产生**256位**的消息摘要。SHA-256与SHA-1相比，在安全性和抗碰撞性上更胜一筹，广泛应用于数字签名、证书签名、文件完整性校验等领域。
### SHA-128
SHA-128是SHA-2算法族中的一种，其以512位的消息分块为基础，产生一个**128位**的消息摘要。与SHA-256相比，SHA-128在安全性和抗碰撞性上较弱，但计算量较小，适用于对安全性要求较高但计算资源有限的场景。

##  VS 加密算法 
摘要算法是不可逆计算，由原始数据计算，得到哈希值，不能由哈希值计算出原始数据；
> 能还原回去，应该考虑 压缩算法；


加密算法是可逆计算，由原始数据计算，得到密文，利用解密钥匙，可以将密文还原为原始数据；
